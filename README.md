# Nebula

VPN-клиент для Android на ядре **Xray** с брендингом Nebula. Поддерживает **VLESS, VMess, Trojan, Shadowsocks**, подписки по ссылке, Reality / TLS / WebSocket / gRPC.

Основан на открытом проекте [v2rayNG](https://github.com/2dust/v2rayNG) (GPL-3.0). Сборка идёт целиком в GitHub Actions, исходники v2rayNG подтягиваются при сборке, поверх накладываются название, иконка и стили из папки `android-overlay/`.

## Как получить APK
1. Откройте вкладку **Actions** → **Build APK** → **Run workflow**.
2. Через 10–15 минут скачайте артефакт **Nebula-apk** (ZIP с `.apk` внутри).
3. Установите `.apk` на телефон (разрешите установку из неизвестных источников).

Подпись приложения хранится в кэше Actions, поэтому новые версии ставятся поверх старых.

## Структура
- `.github/workflows/build-apk.yml` — сборка APK
- `android-overlay/res/` — иконки приложения (накладываются поверх v2rayNG)

## Планы
- Интерфейс в стиле Material You 3 (динамические цвета, жирный шрифт)
- Экран приветствия, приветствие по времени суток
- Свои обои, карточки серверов с пингом

## Лицензия
GPL-3.0, как у v2rayNG. Исходный код должен оставаться открытым.
